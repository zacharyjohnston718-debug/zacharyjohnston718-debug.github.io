Tire data analysis

MATLAB fitters that turn tire test data into Pacejka Magic Formula models of lateral and longitudinal force, aligning moment and combined slip. The fitted model now runs inside the FSAE Suspension App, where it informs the vehicle calculations.

Approach

The data are Formula SAE Tire Test Consortium runs for a Hoosier 43100. Each channel is fitted to the Magic Formula 6.1.2 form with MATLAB's lsqnonlin, using a robust Huber loss (iteratively reweighted) so outlier samples don't drag the fit, and multiple starting points so the optimizer doesn't settle in a poor local minimum. Error is tracked per channel.

In the app, the tire module shows the force curves, compares test conditions, and labels each result with the range of data that supports it, so extrapolated regions aren't mistaken for measured ones.

Validation

I evaluated each fit on test runs that were not used to fit it. Error stayed between 2.6% and 3.0% of each normal load's measured peak force. [anything else you checked]

Results

The model is the Suspension App's tire model: it feeds tire-informed limits, the tire operating-point study (sensitivity to load, camber and pressure) and the cornering, braking and traction load cases, in place of a single assumed friction coefficient.
